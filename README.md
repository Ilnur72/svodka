# УзКТМК — ситуацион марказ дашборди

Ишлаб чиқариш ва ресурслар мониторинги. Маълумот **Production Report API** дан
реал вақтда олинади; иловада статик маълумот сақланмайди.

## Бўлимлар

| Роут | Бўлим |
|---|---|
| `#obzor` | Умумий кўрсаткичлар |
| `#prod` | Ишлаб чиқариш |
| `#sgp` | Сотиш ва қолдиқлар (СГП) |
| `#energy` | Электр энергия |
| `#h2` | Водород ва газ |
| `#cist` | Цистерна ва юклар |
| `#ogarok` | Огарок |
| `#ing` | Ингичка ИОФ |

Давр юқоридаги панелдан танланади (ой рўйхати ва тайёр оралиқлар) ва барча
бўлимларга бирдек таъсир қилади. Танлов URL'да сақланади — линк билан
улашса бўлади.

## Ишга тушириш

```bash
cd dashboard
npm install
cp .env.example .env      # API манзилларини ёзинг
npm run dev               # http://localhost:5173
```

`.env`:

```
VITE_API_BASE=https://<host>/api/production-report
VITE_AUTH_BASE=https://<host>/api
```

Кириш `/auth/login` орқали (email + парол). Токен `sessionStorage` да сақланади
ва **build ичига кирмайди**. `401` келса фойдаланувчи кириш саҳифасига
қайтарилади.

## Йиғиш ва деплой

```bash
npm run build             # tsc --noEmit && vite build  →  dist/
```

`dist/` — статик файллар (≈700 KB), Node керак эмас.

SPA бўлгани учун сервер номаълум йўлларни `index.html` га йўналтириши керак:

```nginx
server {
  listen 80;
  server_name dashboard.example.uz;
  root /var/www/tmk-dashboard;

  location / {
    try_files $uri $uri/ /index.html;
  }

  location /assets/ {
    expires 1y;
    add_header Cache-Control "public, immutable";
  }
}
```

`index.html` кешланмаслиги керак — акс ҳолда фойдаланувчи эски build'да
қолиб кетади.

## Тузилма

```
dashboard/src/
  api/          client (токен, 401, 404 → «бўлим мавжуд эмас»), endpoints, types
  lib/adapters/ API жавоби → панел кутадиган view-model
  lib/          format, period, theme, useQuery, dataQuality
  components/   диаграммалар ва UI бўлаклари
  panels/       8 та бўлим + кириш саҳифаси
```

Панеллар API тузилмасини билмайди — фақат адаптерлар билади. API ўзгарса
адаптер тузатилади, панеллар тегилмайди.

## Кўрсаткичлар бўйича қоидалар

Булар рақамларнинг тўғри ўқилиши учун. Ҳар бири кодда изоҳланган —
ўзгартиришдан олдин сабабини ўқинг:

1. **Турли ўлчов бирликлари ҳеч қачон битта шкалага қўйилмайди.** Тонна, кг,
   дона ва м³ алоҳида карточкаларда: юзлаб тонна ёнида бир нечта донали
   устун кўринмай кетади.
2. **Иккита Y ўқли диаграмма йўқ** — икки шкалани ёнма-ён қўйиш сунъий
   боғлиқлик ясайди.
3. **Сон яхлитланмайди** (`exact()`): манбадаги 14,108 экранда ҳам 14,108.
   Яхлитлаш фақат ўқ белгиларида, у ерда жой йўқ.
4. **«Всего» сатрлари** (`isTotal`) йиғиндиларга, четланиш рўйхатларига ва
   ҳажм рейтингига **қўшилмайди** — улар пастдаги қаторларнинг йиғиндиси,
   акс ҳолда битта миқдор икки марта саналади. Алоҳида карточкада кўрсатилади.
5. **Режаси йўқ позициялар** фоиз диаграммасига тушмайди (нолга бўлиб
   бўлмайди), лекин алоҳида жадвалда кўрсатилади — уларда факт бўлиши мумкин.
6. **Ўлчов бирлиги шубҳали қаторлар** (`unitSuspect`) базадаги қиймати билан
   кўрсатилади, ёнида ⚠ белгиси ва сабаби. Ҳеч нарса яширилмайди.
7. **Битта цех танланганда** тўлиқ рўйхат чиқади, «барчаси» да эса энг чекка
   позициялар — ўртадаги қаторлар кўринмай қолмаслиги учун.

## Маълумот сифати

`src/lib/dataQuality.ts` ва `src/lib/workshopFixes.ts` — импорт хатолари
топилганда вақтинчалик клиент тузатишлари учун жой. **Ҳозир иккови ҳам бўш**:
барча тузатишлар бэкендда қилинган ва дашборд базадаги маълумотни
ўзгартирмасдан кўрсатади.

Янги хато топилса ўша файлларга қатор қўшилади, бэкенд тузатгач олиб
ташланади — панеллар тегилмайди.
