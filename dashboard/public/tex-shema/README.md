# `public/tex-shema/` — ускуна расмлари

Манба: **«Баланс (2).pptx»** (`svodka/` илдизида), 1-слайд —
«Графическая схема технологического процесса Ингичкинской вольфрамовой
обогатительной фабрики». Расмлар презентациянинг ўзидан ажратиб олинган
(`ppt/media/`), таҳрирланмаган, фақат номи ўзгартирилган.

Файллар `import.meta.env.BASE_URL` орқали чақирилади — `public/invest/`
даги каби (қаранг: `lib/adapters/invest.ts`). Бандлга кирмайди, шунинг
учун файл номи ўзгарса кодда ҳам ўзгартириш керак.

Биринчи тўрттаси слайддаги **жойлашув** билан тасдиқланган (ёрлиққа энг
яқин расм). Охирги учтаси слайднинг пастки «иллюстрация» қаторида
турибди — уларда яқинлик билан боғлаш ишламайди, шунинг учун **расмнинг
ўзидаги ускуна** бўйича аниқланган. Ҳар бири 1-слайддаги ускуна номлари
рўйхатидан: конвейер · скруббер · винтовой сепаратор · гравитационный
стол · участок флотации · участок сушки концентратов · мелница — еттита
ном, еттита расм.

## Диққат

Расмлар — **ускуна турининг иллюстрацияси**, Ингичка фабрикасидаги
айнан шу ускунанинг сурати эмас (презентацияда ҳам шундай ишлатилган).
Уларга миқдорий маъно юкланмайди.
